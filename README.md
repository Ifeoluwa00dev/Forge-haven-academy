
# Forge Haven Academy 🎓

### Modern Educational Platform | Next.js • TypeScript • Supabase • Stripe

Forge Haven Academy is a web-based educational platform designed to provide learners with access to online courses and educational resources.

The platform supports both free learning opportunities and paid course enrollment, with an emphasis on responsive design, straightforward navigation, and accessible learning experiences.

🌐 **Live Website:** [www.forgehavenacademy.com](https://www.forgehavenacademy.com/)

---

## 📌 Project Overview

Forge Haven Academy brings educational content and course access into a unified web experience.

The project combines modern frontend development with backend services and payment integration to support a practical online learning workflow.

### Key Features

- **Responsive User Interface** — Layouts designed for desktop, tablet, and mobile devices.
- **Course Access** — Support for both free and paid educational content.
- **Stripe Integration** — Payment checkout functionality for paid courses.
- **Free Learning Access** — Free classes remain accessible without requiring a paid purchase.
- **Modern Frontend Architecture** — Built using Next.js and reusable React components.
- **Backend Integration** — Supabase integration for application data and services.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm or another compatible package manager
- Required environment variables and service credentials

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Ifeoluwa00dev/Forge-haven-academy.git
   ```

2. Navigate into the project:

   ```bash
   cd Forge-haven-academy
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables.

   Use the environment variable names documented in the project configuration. Never commit real API keys or credentials.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open [http://localhost:3000](http://localhost:3000).

> Some features, including payments and backend-connected workflows, require valid service configuration.

---

## 🔐 Security & Configuration

This project uses external services for backend functionality and payment processing.

- Store credentials in environment variables.
- Do not commit `.env.local` or production secrets.
- Use Stripe test credentials when developing payment functionality.
- Keep server-side credentials out of client-side code.
